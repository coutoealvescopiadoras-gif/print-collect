 4. PASSO-A-PASSO PARA BUILDAR O SETUP 6.9.1 (NO NOTEBOOK NOVO):
=========================================================================

Abra o POWERSHELL ou CMD COMO ADMINISTRADOR.

--------------------------------------------------------------------------------
PASSO 1: CLONAR O REPOSITÓRIO (ou copiar pasta da VM)
--------------------------------------------------------------------------------
  Se for usar Git (recomendado — sempre pega última versão do código):
    mkdir C:\Workspace
    cd C:\Workspace
    git clone https://github.com/coutoealvescopiadoras-gif/print-collect.git
    cd print-collect
  Se for COPIAR pasta da VM antiga:
    Copie a pasta inteira C:\Users\Julio\Desktop\print-collect (da VM Mac)
    para C:\Workspace\print-collect no notebook novo.
    Depois: cd C:\Workspace\print-collect

--------------------------------------------------------------------------------
PASSO 2: ENTRAR NA PASTA DO AGENTE E CRIAR AMBIENTE VIRTUAL VENV (32-bit!)
--------------------------------------------------------------------------------
  cd C:\Workspace\print-collect\agent
  rmdir /s /q venv      ← apaga venv antiga, se existir
  python -m venv venv   ← cria nova venv (usa Python 3.10 x86)
  venv\Scripts\activate ← ativa a venv
  ✅ A linha do prompt agora começa com "(venv)". Confirma que deu certo.

--------------------------------------------------------------------------------
PASSO 3: INSTALAR DEPENDÊNCIAS DO AGENTE + PYINSTALLER
--------------------------------------------------------------------------------
  python -m pip install --upgrade pip
  pip install -r requirements.txt
  pip install pyinstaller
  pip install pysnmp pysnmp-pyasn1 pysnmpcrypto   ← se precisar de SNMP
  (se alguma der erro por versões, me chama que a gente acerta.)

--------------------------------------------------------------------------------
PASSO 4: BUILDAR O EXECUTÁVEL DO AGENTE (COM PYINSTALLER)
--------------------------------------------------------------------------------
  Primeiro: veja se tem arquivo de build já existente na pasta agent\
    dir *.spec
    dir build_*.bat build_*.cmd
    dir setup*.iss

  CASO 1 — Se existir agent.spec (PyInstaller specfile):
    pyinstaller --clean --noconfirm agent.spec

  CASO 2 — Se existir build_setup.cmd ou build_agent.bat (script de build):
    build_setup.cmd   (ou o nome que tiver)

  CASO 3 — Se NÃO tiver nada:
    Me chama! A gente cria o .spec ou o .bat com as flags certas
    (--onefile --name PrintCollectAgent etc.) na hora.

  RESULTADO FINAL DO PASSO 4:
    Vai existir um arquivo EXE em C:\Workspace\print-collect\agent\dist\
    Geralmente: PrintCollectAgent.exe

--------------------------------------------------------------------------------
PASSO 5: COMPILAR O INSTALADOR (.EXE) COM INNO SETUP
--------------------------------------------------------------------------------
  1. Abra o Inno Setup Compiler (Menu Iniciar → Inno Setup 6 →
     Inno Setup Compiler).
  2. Menu File → Open → navegue até C:\Workspace\print-collect\agent\
     Procure por arquivo com extensão .iss
     (ex: PrintCollectSetup.iss, setup.iss, etc.)
  3. Abra o .iss.
  4. Verifique a versão (linha AppVersion=): Mude para 6.9.1, se não for.
  5. Aperte F9 (ou clique no botão verde ▶️ "Run / Compile").
  6. Aguarde compilar (alguns segundos a 1 minuto).

  RESULTADO FINAL DO PASSO 5:
    Vai existir um instalador em C:\Workspace\print-collect\agent\Output\
    Nome geralmente: PrintCollectSetup_6.9.1.exe
    → ESSE É O ARQUIVO QUE VOCÊ VAI DISTRIBUIR PARA TODOS OS CLIENTES!
